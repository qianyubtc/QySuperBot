# 币安聊天接入（实验）

支持普通聊天室。可以使用服务器登录直连，或使用 Chrome 扩展桥接。平台接口与登录策略可能变化，不承诺永久令牌、独立续签或长期免登录。

## 能力范围

- 读取账号已加入的聊天室，后台勾选同步范围，取消同步后保留历史。
- 同步文本、图片、昵称和头像，后台回复文字，群发支持单图和图片说明。
- 首次导入近期历史，不对旧消息重放审核、同步或处罚。
- 服务器直连提供手动禁言、手动解禁及免费普通群踢人。付费群仅开放单独禁言/解禁，VIP 社群管理不可用。
- 禁言持续到管理员手动解禁；删消息、平台封禁、自动入群验证与限时禁言未接入。
- 成员操作保护群主、管理员、子管理员与执行账号自身。提交前和执行前重新核对身份、目标、群类型与同步范围。
- 操作成功需要平台响应和状态回读相符；结果不明时标为待核对，不自动重试。真实成员写操作仍需在独立测试群验收。

## VPS 浏览器登录

Linux 服务端需安装 Google Chrome、Xvfb、xauth，启用 `BINANCE_BROWSER_ENABLED=true` 并设置浏览器路径。配置见 `.env.example` 和 [运行说明](operations.md)。

1. 后台“连接账号”创建币安连接。
2. 点击“登录币安”，在后台显示的 VPS 浏览器中完成人工扫码、验证码和平台二次认证。
3. 点击“连接此账号”。服务端核对身份、消息读取及聊天心跳后保存必要凭据，成功后关闭登录浏览器，由服务端继续同步。
4. 点击“管理同步群”，勾选需要接入的群。

网页登录身份必须匹配原连接记录，不能借重新登录覆盖其他账号。Cookie 仅保存在自己的服务器；凭据使用 AES-256-GCM 加密，后台列表、审计和错误响应不回显原值。请使用专用账号。登录窗口仅管理员可访问，校验同源、会话、CSRF 与窗口标识。

可手动填入同一会话的 `p20t`、`cr00` 与可选 `BNC_FV_KEY`；无需交易 API Key，不接受完整 Cookie。网页与聊天令牌可能是 JWT，也可能为不透明格式；解析 JWT 声明不等于验证签名或可信身份。真正身份通过聊天接口和聊天令牌身份共同核对。

## Chrome 桥接

```sh
npm ci
npm run package:binance-extension
```

解压构建出的扩展 ZIP，在 Chrome 的 `chrome://extensions` 开发者模式中“加载已解压的扩展程序”。后台创建连接后，将配对 JSON 填入扩展。配对目标应为自己的 HTTPS/WSS 后台，例如 `wss://bot.example.com/api/v1/connectors/binance/socket`。

同一 Chrome 配置打开并登录 `https://www.binance.com/zh-CN/square/chat`，更新扩展后刷新聊天页，再使用已保存配置连接。桥接模式需要浏览器与标签保持打开，Cookie 默认留在浏览器。

扩展可选的一键授权直连流程由管理员主动点击触发，临时申请 cookies 权限，只读取所需字段，并通过绑定账号、用途、挑战与字段摘要的签名提交到已配对后台；结束后撤回权限。不枚举完整 Cookie，不订阅变化或自动上传。此独立授权流程仍需按实际 Chrome 环境验收。

## 状态与恢复

后台区分连接正常、登录失效、身份不一致、平台访问受限、临时网络失败与群权限不足。只有明确鉴权失败或网页登录令牌声明已过期才要求重新登录；HTTP 403、限流或聊天令牌短期过期不单独视为网页登录失效。

失效后从“连接账号 → 重新登录币安”恢复。新会话通过验证才切换，不确定的旧发送任务不会因重连自动重发。账号暂停、群取消同步、配对轮换和会话变化会使旧请求失效，迟到结果不能覆盖新状态。

诊断接口仅向管理员提供受限字段：

```text
GET  /api/v1/accounts/:id/binance-diagnostics?group_id=GROUP_ID
POST /api/v1/accounts/:id/binance-send-check
GET  /api/v1/conversations/:id/binance-members?user_id=CHAT_UID
POST /api/v1/conversations/:id/binance-member-actions
```

`binance-send-check` 只验证聊天连接和心跳，不发送群消息。成员写操作正文为 `{user_id, action: "mute" | "unmute" | "remove", reason}`，要求管理员会话、CSRF 和幂等请求键。图片上传遵循群预上传与完成通知流程，不额外补发图片帧；未确认群、发送者、对象键与文案的结果进入待核对。

引用回复、账号自然过期后的恢复、浏览器版本兼容与长期稳定性，均应在自己的部署环境中单独验证。
